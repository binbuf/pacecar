## Exact commands that work
- Build Debug: `pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Configuration Debug`
- Build+test Release: `... -Configuration Release -Test`
- Harness verify: `pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/verify.ps1` (Release|x64; green)
- MSBuild: `& <vswhere -find MSBuild\**\Bin\MSBuild.exe> pacecar.slnx /m /p:Configuration=Release /p:Platform=x64`
- Manifest check: `mt.exe "-inputresource:out\x64\Release\Pacecar.Overlay.exe;#1" -out:m.xml`
- Static CRT check: `dumpbin /dependents out\x64\Release\Pacecar.Overlay.exe` → only USER32/KERNEL32.

## Gotchas / decisions later tasks must respect
- **New native projects must import both `..\..\build\Directory.Build.props` (right after
  `Microsoft.Cpp.Default.props`) and `..\..\build\Directory.Build.targets` (after
  `Microsoft.Cpp.targets`).** They are not auto-discovered because they live in `build/`.
- `VcpkgConfiguration` is set explicitly in the props; without it, Debug builds link Release vcpkg
  libs (props import precedes `UseDebugLibraries`).
- `VCPkgLocalAppDataDisabled=true` avoids double-importing the VS per-user vcpkg props (MSB4011).
- gtest's `gtest_main.lib`/`gmock_main.lib` are in vcpkg `lib\manual-link` and are NOT autolinked;
  add `gtest_main.lib` to `AdditionalDependencies`.
- Release enables `/analyze`; third-party headers are suppressed via `DisableAnalyzeExternal` +
  `ExternalWarningLevel=TurnOffAllWarnings` (valid enum value is `TurnOffAllWarnings`, not `Level0`).
  `Pacecar.App.Tests` sets `EnablePREfast=false` (gtest C6326 false positive).
- Output/intermediate dirs are `out\<Platform>\<Configuration>\` and
  `out\obj\<Project>\<Platform>\<Configuration>\` (set in `Directory.Build.props`).
- `.gitignore` negates `build/Directory.Build.props`/`.targets` because the harness auto-ignores a
  top-level `build/` dir. `out/` and `vcpkg_installed/` are ignored.
- `docs/` is currently ignored by `.gitignore`; harness force-adds planning docs. `docs/BUILDING.md`
  and the ADR live there.
- Toolset is `v145` (VS 18). `scripts/verify.ps1` was changed to discover test exes under `out/`
  only, so stale `legacy/**/testhost.exe` cannot be run.
